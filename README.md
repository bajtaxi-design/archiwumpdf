# ArchiwumPDF v1.1

**Profesjonalne, w 100% darmowe i offline narzędzie do tworzenia plików PDF ze zdjęć.**  
Zoptymalizowane pod iPhone / iPad (PWA).

Stworzone dla Kustosza **Archiwum 13 SAS**.

---

## Funkcje

- Wybór wielu zdjęć z galerii (JPEG, PNG, **HEIC**)
- **Drag & Drop** zmiany kolejności (działa na dotyk)
- Trzy poziomy kompresji (Wysoka / Średnia / Silna)
- Numery stron
- Opcjonalny tekst nagłówka
- Watermark „Archiwum 13 SAS”
- Pasek postępu podczas generowania
- Tryb ciemny
- Całkowicie offline po pierwszym załadowaniu
- Pobieranie + udostępnianie przez systemowy Share Sheet na iOS

---

## Szybki start (lokalnie)

```bash
cd archiwumpdf
npm install
npm run dev
```

### Dodanie do ekranu początkowego (iPhone)

1. Otwórz aplikację w **Safari**
2. Kliknij **Udostępnij** → **Dodaj do ekranu początkowego**
3. Gotowe

---

## Wdrożenie na Vercel

1. Wejdź na [vercel.com](https://vercel.com) → New Project
2. Importuj repozytorium `archiwumpdf`
3. Framework: **Vite**
4. Deploy

Po deployu dostaniesz link, który możesz dodać do ekranu początkowego na iPhonie.
